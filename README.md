## 先确认你要的是哪一种"开服"

很多人搜基岩版服务器，其实需求完全不同，先把路线分清再花钱：

1. **官方 Realms（领域）**：在游戏里直接订阅，开服零门槛。代价是每月持续付费、人数和配置受官方限制，行为包的折腾空间也小。
2. **本机开房 + 局域网联机**：免费，但只有同一网络下的设备能进，房主一退出游戏服务器就没了。想给外地朋友玩，还得额外做内网穿透。
3. **自建服务器**：用官方 Bedrock Dedicated Server（BDS）或第三方内核，跑在一台常年开机的机器上。掌控度最高，也能长期保留地图——代价是要有一台机器和一个公网入口。

第三种的"机器"不一定是家里的旧电脑。家宽的公网 IP、上行带宽、断电断网都是现实问题，一台入门云主机通常比让家里路由器 24 小时待命更省心。

## 基岩版开服和 Java 版完全是两套逻辑

从 Java 版转过来的人最容易在这里翻车：

- **协议和端口不同**。基岩版服务端默认监听 **19132 端口，走 UDP**；Java 版是 25565/TCP。在云服务商的控制台做端口映射时，协议一定要选 **UDP**，选成 TCP 就是连不上还查不出原因。
- **客户端覆盖面不同**。基岩版客户端覆盖 Windows、Android、iOS、Xbox、PlayStation、Switch，一台服务器能让手机和主机玩家同时进来；Java 版客户端只在 PC 上。
- **服务端内核不同**。基岩版跑的是 BDS、Nukkit、LeviLamina 这类内核，Paper、Spigot、Forge、Fabric 那一整套 Java 插件生态在这里用不了，玩法扩展靠行为包和资源包。
- **版本必须对得上**。基岩客户端一般会自动更新到最新版，服务端落后就会出现 "Outdated Server"。所以选的服务端要能方便地换版本。

> 还有一点：国内应用商店下载的网易版《我的世界》是另一套体系，自建的 BDS 服务器对应的是国际版基岩客户端，两边不能混着连。

## 一台能跑基岩服的机器，到底要什么配置

Minecraft 官方给 BDS 的最低要求是：CPU 相当于 Intel Core i3 3210 / AMD A8 7600、4GB 内存、180MB 到 1GB 可用空间，系统为 Ubuntu 22.04（LTS）及以上，或 Windows 10 10.0.15063 / Windows Server 2016 及以上。

注意这是"能启动"的门槛，不是"能一起玩"的门槛。实际开服几年的人给出的经验值更实用：

- **2 核 4G**：几个人到十人以内的纯净生存，视距别拉太远，够用。
- **4 核 8G**：十几人同时在线、装了一些行为包、地图已经很大的存档，从这里起步比较稳。
- **6 核 12G 以上**：人数多、视距大、红石机器和刷怪塔密集的大型生存服。

另外两点容易被忽略：

- **单核性能比核心数更重要**。MC 的服务端主线程一直是瓶颈，一颗高主频的 CPU 比多给两个核心更有用。
- **磁盘要留余量**。地图文件会一直长大，30G 系统盘跑几个月就可能捉襟见肘，带独立数据盘的方案更从容。

带宽反而不是重点。基岩版的同步数据量不大，10Mbps 上行撑十来个人没问题；真正影响手感的是线路延迟，选国内机房对国内玩家明显更友好。

## 固定计费还是动态计费？

雨云游戏云有两种计费方式，选错的话一个月能差出不少钱。

**动态计费**的逻辑是：基础租金很低，但 CPU 使用率超过 20% 的部分要按"CPU 电量"日结。电量单价按机型区分——E5 2666v3 / Platinum 8259CL 是 0.0005 元/电量，Gold 6146 / Platinum 8275CL 是 0.0006，Ryzen 5900X / EPYC 7A23 是 0.0008，9950X / 7950X / 13900K / 14900K 是 0.001 元。每天还会按核心数赠送一定免费电量，用不完可以叠加到后面。

**固定计费**就是传统包月，租金高一些，但对使用率完全不敏感。

怎么选？雨云论坛里有玩家做过实测：一台 3 核 6G 的生存服，下午三四个小时进了三四个玩家，烧掉了 400 多电量，半天接近 1000 电量，按这个速度一个月大概要多花 30 元——这种情况下固定计费反而更划算。官方给的参考案例也差不多：2 核 Gold 6146 机器跑纯净服 5 人，平均使用率 25% 左右时每天大约 0.3 元；跑到 20 人规模、平均使用率 40% 时，每天就接近 1.5 元。

结论可以简化成两句话：

- **每天稳定玩两小时以上、而且经常有人在线**（尤其是生存服）→ 固定计费，省心也更便宜。
- **偶尔开一次、单纯给几个人玩几个小时、或者只是测试** → 动态计费，闲置时几乎不产生费用。

两种模式可以随时互相切换，配置也能升降，所以不必一次赌对，先用动态计费跑一周，看账单再决定。

## 进不去服务器时，按这个顺序排查

**提示 Outdated Server / Outdated Client**：客户端和服务端协议版本不一致。基岩版连小版本号变了协议也会变，把服务端升级到与客户端一致的版本即可。这也是为什么面板服选 BDS 时要跟着客户端版本更新。

**一直卡在"正在连接"**：九成是端口问题。确认映射的协议是 **UDP**，确认游戏里填的是**对外端口**而不是 19132，确认内网的 `server-port` 和映射端口一致。

**换了端口才连上**：正常现象。共享 IP 环境下 19132 通常被别人的项目占着，随机端口反而更稳。

**只有部分人能进**：检查 `online-mode`（在线模式需要正版 Xbox 账号）、允许名单 `allow-list` 是否开启，以及是不是用了网易版客户端。

**延迟高、方块回弹**：多半是机房离玩家太远。国内玩家为主的服，优先选国内节点。

**地图丢了**：养成用面板备份的习惯。雨云面板支持备份还原和定时备份任务，开服前设一次，比事后找文件强。
